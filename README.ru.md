# Progress Bar

Плагин для Obsidian, который отображает настраиваемые индикаторы прогресса на основе выполненных Markdown-чекбоксов.

## Возможности

- Расчёт прогресса на основе Markdown-чекбоксов.
- Отображение прогресса в режиме чтения и Live Preview.
- Отображение процента выполнения и количества задач.
- Поддержка русского и английского языков.
- Современный и классический стили Progress Bar.
- Настройка цветов, толщины границы и радиуса скругления.
- Возможность включить или отключить отображение счётчика задач.
- Сброс настроек к значениям по умолчанию.
- Вставка Progress Bar через контекстное меню или Command Palette.
- Поддержка отдельных областей подсчёта с помощью `[progressBar]` и `[/progressBar]`.

## Использование

### Обычный Progress Bar

Добавьте Markdown-задачи в заметку:

```
- [x] Выполненная задача
- [x] Ещё одна выполненная задача
- [ ] Невыполненная задача
- [ ] Ещё одна невыполненная задача
```

Затем добавьте:

```
[progressBar]
```

Плагин рассчитает прогресс на основе всех Markdown-чекбоксов в заметке.

Например, если выполнены 2 задачи из 4:

```
50%    2 из 4 выполнено
```

### Progress Bar для отдельного блока

Можно ограничить область подсчёта определённым разделом заметки:

```
[progressBar]

- [x] Задача 1
- [x] Задача 2
- [ ] Задача 3
- [ ] Задача 4

[/progressBar]
```

В этом случае учитываются только чекбоксы, расположенные между `[progressBar]` и `[/progressBar]`.

Это позволяет создавать несколько независимых Progress Bar в одной заметке:

```
# Проект A

[progressBar]

- [x] Задача A1
- [x] Задача A2
- [ ] Задача A3

[/progressBar]

# Проект B

[progressBar]

- [x] Задача B1
- [ ] Задача B2
- [ ] Задача B3
- [ ] Задача B4

[/progressBar]
```

Каждый Progress Bar рассчитывает прогресс независимо от остальных.

## Установка

### Community Plugins

Установите **Progress Bar** через каталог Community Plugins в Obsidian.

### Ручная установка

Скачайте последний релиз с GitHub и скопируйте следующие файлы:

```
main.js
manifest.json
styles.css
```

в папку:

```
.obsidian/plugins/progress-bar/
```

После этого откройте Obsidian и включите **Progress Bar** в:

**Settings → Community plugins**

## Разработка

Клонируйте репозиторий и установите зависимости:

```
npm install
```

Запустите сборку в режиме разработки:

```
npm run dev
```

Для создания production-сборки:

```
npm run build
```
